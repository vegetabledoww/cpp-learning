## 队列与循环队列

`queue` 像排队：后面加入，前面离开。`front()` 只读取队头，`pop()` 只删除队头，不返回被删除的值。`deque` 可以在两端加入和删除，是单调队列的常用底层容器。

循环队列使用固定长度数组，记录队头下标 `head` 和有效元素数 `count`。下一个入队位置是 `(head + count) % capacity`。出队只移动队头并减小数量，不需要搬动数组元素。

例如容量为 3，入队 1、2、3 后出队 1，再入队 4，底层数组是 `[4,2,3]`，但逻辑队列是 `[2,3,4]`。数组排列不一定等于出队顺序。

## 从滑动窗口和到滑动窗口最大值

窗口和可以通过“减去离开的值，加上进入的值”更新。最大值不能这样相减：最大值离开后，还要知道剩余元素里谁最大。

单调队列保存有机会成为最大值的元素下标，保持下标递增、对应值递减：

1. 从队头移除过期下标。
2. 从队尾移除比新值小或相等的候选值。
3. 加入新下标；窗口凑满后，取队头对应的值作为答案。

第二步成立的原因：新元素更大或相等，而且更晚离开窗口，因此旧元素之后不可能比新元素更合适。相等时保留较新的下标即可。

每个下标只入队一次、出队至多一次，所以虽然有 `while`，总时间仍是 O(n)。负数不会影响这种大小比较。

## 二叉树与二叉搜索树

前序、中序、后序的差别，只在于把“访问根”放在左右递归的什么位置。三者都会访问全部节点；普通二叉树的中序结果不保证有序。

二叉搜索树多了大小约束：左子树比根小，右子树比根大。因此查找只走一侧，中序得到有序序列。示例约定重复值不插入。

注意 `root = Insert(root, value)`：空树插入时会产生新的根，递归插入时也要把返回指针连回父节点。动态创建的节点最后按后序释放，先子节点、后父节点。

这份实现没有自平衡。有序输入会使树退化为链，所以单次插入和查找是 O(h)，最坏 O(n)，不能一概写成 O(log n)。

## 并查集

把每个集合想成一棵父指针树，根节点代表这个集合。`Find(x)` 找根；`Connected(a,b)` 比较两个根；`Unite(a,b)` 连接两个不同的根。

直接比较 `parent[a] == parent[b]` 不可靠：同一集合里的节点可能有不同的直接父节点。必须找到各自的根。重复合并和自己与自己合并都不会减少集合数量。

路径压缩让查找路径上的节点直接指向根；按大小合并让小集合挂到大集合。二者结合，使反复查询和合并非常快。并查集适合维护连通分组，不保存具体路线，也不能直接删除连接。
