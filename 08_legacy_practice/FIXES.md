## 基础语法与内存

- 深拷贝：修正将 `sizeof(pointer)` 当作缓冲区长度、`delete` 与 `new[]` 不配对、析构不释放等问题。赋值先分配成功再替换旧数据，并保留自赋值保护。
- `move/forward`：有名字的右值引用变量作为表达式仍是左值；`move` 本身不搬运资源。
- 字符和布局：`memcpy` 不自动追加终止符；`memset` 填充字节；C++ 支持位域，但布局不能作为可移植序列化约定。移除读取未初始化字节或非活动 union 成员的做法。
- `atoi`：溢出发生前检查阈值；不能靠“int 已经变负”判断，因为有符号溢出是未定义行为。
- 链表创建：已有首节点后从第二字符继续，避免首字符重复；动态创建的测试节点正常释放。其它链表测试用拥有节点的 vector 自动管理内存。
- 线程：通过 join 等待完成后读取结果，不靠 sleep 推测；纠正 join 是“加入主线程”的说法。
- 合并有序数组：将非标准变长栈数组替换为 vector。
- 独立源码只引用实际需要的标准头文件，不继承旧电脑上的绝对 assist.h 路径。

## 数值与复杂度

- K-means：校验 k<=点数，清空重复调用状态；空簇保留中心，避免除零；用中心移动量判断收敛，加迭代上限并报告是否收敛。原“总距离>20就继续”不能保证终止。
- 经纬度：cos 的参数转为弧度；正反转换用相同基准纬度和地球半径。示例明确限制为远离极点的小范围近似，不再用跨洲坐标验证局部公式。
- 协方差：原单变量序列中心化外积不是多变量样本协方差；学习版明确行=样本、列=变量，至少两个样本，计算中心化矩阵的转置乘积/(n-1)。
- 第 K 大保留逐个入堆版本，复杂度不是原注释的 O(n)；LFU 保留 set 版本，操作 O(log capacity)，明确不冒称满足原题 O(1)；非递归快排不保证必然比递归省空间。
- 零钱兑换 II：最终答案能放进 int 不代表所有中间金额的计数都能放入。非负加法封顶 INT_MAX，保留承诺范围内答案，测试大量偶面额与不可达奇目标。
